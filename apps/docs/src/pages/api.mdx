# API Reference

## `devsess`

### `defineDevCli(config)`

Scaffolds a persistent dev CLI. Returns `(argv: string[]) => void`.

```ts
import { defineDevCli } from 'devsess'

defineDevCli({
	name: string,
	dir: string,
	options?: Record<string, cli.Flag<any>>,
	run: (ctx: RunContext, opts: ResolvedOptions) => Effect<void, any, any>,
})
```

| Field | Type | Description |
|-------|------|-------------|
| `name` | `string` | Name of the CLI program |
| `dir` | `string` | Project root — sessions are created under `<dir>/.data/sessions/` |
| `options` | `Record<string, Flag>` | Extra `effect/unstable/cli` flags to parse (optional) |
| `run` | `(ctx, opts) => Effect` | Your dev script body |

#### `RunContext`

The `ctx` object passed to `run`:

| Member | Type | Description |
|--------|------|-------------|
| `ctx.session` | `Effect<DevSession>` | Resolves the current session |
| `ctx.getStickyPort()` | `Effect<number>` | Returns the session's persistent port (allocating if needed) |
| `ctx.runManagedSubprocess(cmd, args, opts?)` | `Effect<void>` | Start a subprocess that is killed on exit |
| `ctx.publishRunning(data)` | `Effect<void>` | Write a "ready" signal file to the session |
| `ctx.awaitRunning(pkg)` | `Effect<unknown>` | Poll until another service's "ready" signal appears |

---

### `cli`

Re-export of `effect/unstable/cli`. Use it to define flags without adding `effect` as a direct import in your dev script.

```ts
import { cli } from 'devsess'

cli.Flag.boolean('lite')
cli.Flag.string('env')
cli.Flag.integer('workers')
```

---

### `DevSession` (type)

```ts
type DevSession = {
	name: string
	path(rel: string): Effect<string>
}
```

`path(rel)` resolves and ensures the subdirectory `<sessionDir>/<rel>` exists, then returns its absolute path.

---

### `DevSessions`

Effect service tag for the sessions store. Provides `getLatestOrCreate()`.

---

### `makeDevSessionsLayer(rootDir: string)`

Creates a Layer that provides `DevSessions`, scoped to `<rootDir>/.data/sessions/`.

```ts
import { DevSessions, makeDevSessionsLayer } from 'devsess'

Effect.provide(makeDevSessionsLayer('/path/to/project'))
```

---

### `SessionState.slot(schema)`

Creates a typed per-session JSON slot.

```ts
import { SessionState } from 'devsess'
import { Schema } from 'effect'

const slot = SessionState.slot(Schema.Struct({ count: Schema.Number }))

slot.read(session)           // Effect<Option<{ count: number }>>
slot.write(session, { count: 1 })  // Effect<void>
```

## `devsess/pglite`

### `prepareSessionPglite(session, options)`

Prepares a per-session PGlite database from Drizzle migrations. Returns `Effect<{ client, dataDir, dumpPath }>`.

```ts
import { prepareSessionPglite } from 'devsess/pglite'

const { client, dataDir, dumpPath } = yield* prepareSessionPglite(session, {
	migrationsFolder: string,
})
```

---

### `openLitePglite(options)`

Opens a PGlite database at explicit paths. Returns `Effect<PGlite>`.

```ts
import { openLitePglite } from 'devsess/pglite'

const client = yield* openLitePglite({
	dataDir: string,
	dumpPath: string,
	migrationsFolder: string,
})
```

---

### Lower-level helpers

| Export | Signature | Description |
|--------|-----------|-------------|
| `buildPgliteDump` | `(migrationsFolder, dumpPath) => Effect<void>` | Build dump from scratch |
| `ensurePgliteDump` | `(migrationsFolder, dumpPath) => Effect<void>` | Build dump only if missing |
| `migratePglite` | `(client, migrationsFolder) => Effect<void>` | Apply pending migrations |
| `readSqlMigrations` | `(migrationsFolder) => Effect<string[]>` | Read migration SQL files |
| `dumpPgliteToFile` | `(client, dumpPath) => Effect<void>` | Serialize client to file |
| `createPgliteFromDump` | `(dumpPath, dataDir) => Effect<PGlite>` | Hydrate client from dump |
| `getDbMigrationCount` | `(client) => Effect<number>` | Count applied migrations |
| `getExpectedMigrationCount` | `(migrationsFolder) => Effect<number>` | Count migration files |

---

### `PgliteError`

Tagged error thrown by all `devsess/pglite` operations.

```ts
import { PgliteError } from 'devsess/pglite'

// { _tag: 'PgliteError', message: string, cause: unknown }
```

## `devsess/async`

Plain, Promise-based mirror of the `devsess` API above — hides Effect entirely, no `effect` import required in your dev script.

### `defineDevCli(config)`

Same shape as the Effect version, but `run` is `async (ctx, opts) => void` and every `ctx` member returns a `Promise` instead of an `Effect`.

```ts
import { defineDevCli } from 'devsess/async'

defineDevCli({
	name: string,
	dir: string,
	options?: Record<string, cli.Flag<any>>,
	run: (ctx: AsyncRunContext, opts: ResolvedOptions) => Promise<void> | void,
})
```

#### `AsyncRunContext`

| Member | Type | Description |
|--------|------|--------------|
| `ctx.session()` | `Promise<DevSession>` | Resolves the current session |
| `ctx.getStickyPort()` | `Promise<number>` | Returns the session's persistent port (allocating if needed) |
| `ctx.runManagedSubprocess(cmd, args, opts?)` | `Promise<void>` | Start a subprocess that is killed on exit |
| `ctx.publishRunning(data)` | `Promise<void>` | Write a "ready" signal file to the session |
| `ctx.awaitRunning(pkg)` | `Promise<unknown>` | Poll until another service's "ready" signal appears |

---

### `createDevSessions(rootDir)`

Async replacement for `DevSessions`/`makeDevSessionsLayer`, for use outside of `defineDevCli`.

```ts
import { createDevSessions } from 'devsess/async'

const sessions = createDevSessions('/path/to/project')
const session = await sessions.getLatestOrCreate()
```

| Member | Type |
|--------|------|
| `sessions.getSessions()` | `Promise<DevSession[]>` |
| `sessions.createSession()` | `Promise<DevSession>` |
| `sessions.getLatestOrCreate()` | `Promise<DevSession>` |

---

### `DevSession` (type)

```ts
type DevSession = {
	name: string
	path(rel: string): string
}
```

Unlike the Effect `DevSession`, `path(rel)` runs synchronously and returns the absolute path directly (no `Promise`).

---

### `SessionState.slot(schema)`

Same as `devsess`'s `SessionState.slot`, but `read`/`write` return Promises.

```ts
import { SessionState, Schema } from 'devsess/async'

const slot = SessionState.slot(Schema.Struct({ count: Schema.Number }))

await slot.read(session)                 // { count: number } | null
await slot.write(session, { count: 1 })  // void
```

---

### `cli`, `Schema`

Re-exports of `effect/unstable/cli` and `effect/Schema` — same as `devsess`'s `cli`, provided so `defineDevCli`'s `options` and `SessionState.slot`'s schema can be declared without a direct `effect` import.
