# docs

Documentation site for `devsess`, built with [vocs](https://vocs.dev) (v2, on waku + vite).

## Dev
- `pnpm dev` — local dev server
- `pnpm build` — static build

## Layout
- vocs.config.ts — site config + sidebar
- src/pages/*.mdx — one file per page (index, getting-started, dev-sessions, pglite, api)
- src/pages.gen.ts — generated by vocs/waku, gitignored
